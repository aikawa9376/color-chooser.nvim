# color-chooser.nvim

KColorChooser をイメージした、Neovim のフロートウインドウで色を調整するプラグインです。
カーソル下の色コードを読み取り、濃淡を選ぶ面と色相・RGB・HSV・透明度のバーで調整できます。
変更前後の色を並べて表示し、透明度は市松模様の上でプレビューします。

## 必要環境

- Neovim 0.10 以降
- True Color 対応ターミナルと `vim.opt.termguicolors = true`
- 既定の `cmdheight = 1` では、ターミナルの大きさは 48 列 × 24 行以上

外部コマンドや他のプラグインへの依存はありません。

## インストール

lazy.nvim の例:

```lua
{
  "aikawa9376/color-chooser.nvim",
  cmd = "ColorChooser",
  keys = {
    { "<leader>cc", "<cmd>ColorChooser<cr>", desc = "色を調整" },
  },
  opts = {},
}
```

ローカルで試す場合は、上のリポジトリ指定を `dir = "/path/to/color-chooser.nvim"` に置き換えます。
プラグインマネージャーを使わずに確認することもできます:

```sh
nvim --clean --cmd 'set runtimepath+=.' --cmd 'set termguicolors' \
  -c 'runtime plugin/color-chooser.lua' -c 'ColorChooser'
```

## 使い方

1. 色コードの上にカーソルを置き、`:ColorChooser` を実行します。
2. マウスで色の面やバーをクリック・ドラッグするか、下記のキーで調整します。
3. `Enter` で元の色コードを置き換えます。`Esc` / `q` でキャンセルします。

認識できる色コードがない場合は既定色から開始し、確定するとカーソル位置に挿入します。
`:ColorChooser #80aaff` のように開始色を指定することもできます。
カーソル下に色コードがある場合は、そのコードの表記形式で置き換えます。
調整中は元バッファを書き換えず、確定時に一度だけ変更します。

| キー | 操作 |
| --- | --- |
| `Tab` / `j`, `Shift-Tab` / `k` | 操作する面・バーを選択 |
| `h` / `l`, `←` / `→`, `-` / `+` | 値を 1 単位ずつ減らす・増やす |
| `H` / `L` | 値を 10 単位ずつ減らす・増やす |
| 色の面で `↑` / `↓`, `K` / `J` | 明度を上げる・下げる |
| バーで `↑` / `↓`, `K` / `J` | 操作するバーを選択 |
| `e` | 色コードを直接入力（`vim.ui.input`） |
| `f` | 出力形式を HEX → RGB → HSL の順に切り替え |
| `r` | 開始時の色と出力形式に戻す |
| `y` | 色コードを無名レジスタにコピー |
| `Enter` | 確定して閉じる |
| `Esc` / `q` | キャンセルして閉じる |

RGB は 0–255、色相は度、彩度・明度・透明度は百分率で調整します。
マウスを使う場合は `vim.opt.mouse = "a"` など、Neovim 側でマウスを有効にしてください。

## 認識する色コード

```css
#f80
#f80c
#ff8800
#ff8800cc
0xff8800
0xff8800cc
rgb(255, 136, 0)
rgba(255, 136, 0, 0.8)
rgb(100% 53.33% 0% / 80%)
hsl(32 100% 50%)
hsla(32, 100%, 50%, 0.8)
hsl(.09turn 100% 50% / .8)
```

色コードの途中、関数名、括弧内の数値のいずれにカーソルがあっても認識します。
名前付きの色（`red` など）、変数、複数行の色関数は認識しません。

HEX の大文字・小文字、`0x` / `0X`、RGB の百分率表記、CSS のカンマ区切り / 空白区切りを保持します。
短縮 HEX は表現できる場合に維持し、必要なら 6 桁・8 桁へ展開します。
透明度を下げると出力にアルファ値を加えます。数値の空白や小数桁数は整形されます。

元のコードの前に文字が挿入されても置換位置を追跡します。
調整中に対象コード自体が変更された場合は、上書きせず通知します。その場合は開き直してください。

## 設定

`setup()` は省略できます。

```lua
require("color-chooser").setup({
  default_color = "#ff8800",
  border = "rounded",
  width = 64,
  height = 30,
})

vim.keymap.set("n", "<leader>cc", function()
  require("color-chooser").open()
end, { desc = "色を調整" })
```

`width` / `height` はウインドウの内寸です（最小 44 列 / 19 行）。
ターミナルに収まるよう縮小し、リサイズにも追従します。小さい画面では省スペース表示になります。
さらに小さくなった場合はキャンセルして閉じます。
詳細は `:help color-chooser.nvim` を参照してください。

## 開発

```sh
make test
```

依存なしの headless テストで、色の解析・変換・カーソル位置の認識、
フロートの操作、置換・挿入・キャンセル、元コードの変更検出を検証します。
